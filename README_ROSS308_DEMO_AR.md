# Poultry Farm Management V5.6 — بيانات تجريبية Ross 308

هذه **نسخة اختبار** وليست بيانات حقيقية. لم تُعدَّل واجهة البرنامج أو معادلات الحساب.

- 3 مزارع تجريبية؛ كل مزرعة بها 3 عنابر (9 عنابر).
- سعة كل عنبر 20,000 كتكوت.
- 3 دورات لكل عنبر (27 دورة)، بإجمالي 540,000 كتكوت مستلم عبر الدورات.
- سلالة Ross 308 ومعيار Aviagen Ross 308 المرجعي محفوظ داخل كل دورة.
- الدورتان 1 و2 مكتملتان تشغيليًا، والدورة 3 جارية بعمر 41 يومًا بتاريخ 12-10-2026 (لتجربة المتابعة والبيع الجزئي).
- سجلات تجريبية: المتابعة اليومية والنفوق والاستبعاد والمياه والأعلاف والأوزان والتحصينات والأدوية والمبيعات ومصروفات الإيجار والديزل والنشارة والكهرباء والمياه والعمالة والنقل وتحميل الدجاج.
- دفعات شراء علف وأسعار فعلية تجريبية وحركات صرف مرتبطة بالسجلات، دون تكرار تكلفة العلف.
- سجلات تكلفة كتاكيت تتضمن 200 كتكوت مجاني لكل عنبر في الدورة، مع ضريبة شراء قابلة للاسترداد مسجلة بصورة تجريبية.

## التشغيل
1. فك ملف ZIP في مجلد جديد.
2. افتح `v45work/www/index.html`.
3. سجّل دخولًا بحساب **محلي** أو أنشئ حسابًا محليًا. عند أول دخول، تُستبدل بيانات المزارع/العنابر/الدورات الخاصة بهذا الحساب **مرة واحدة فقط** ببيانات الاختبار. لا تتغير كلمة المرور ولا بيانات الحساب.
4. ستظل التعديلات التي تجريها محفوظة داخل المتصفح بعد ذلك، ولا تُعاد تعبئة البيانات عند كل دخول.
5. يمكن استيراد ملف JSON التجريبي المرفق من «النسخ الاحتياطي» يدويًا أيضًا.

**تنبيه:** ملف ZIP للبرنامج لا يحتوي تلقائيًا على بيانات متصفحك القديمة المحفوظة في localStorage. إذا أردت الحفاظ عليها، ينبغي تصدير نسخة JSON من التطبيق القديم قبل استخدام نسخة الاختبار. لا تصلح بيانات هذه الحزمة للتخطيط الفعلي أو الإجراءات البيطرية، فهي أرقام افتراضية للاختبار فقط.
**المزامنة السحابية:** لا تزرع الحزمة بيانات داخل Supabase، والتهيئة التلقائية تتجنب استبدال بيانات حساب مرتبط بخادم Supabase.
