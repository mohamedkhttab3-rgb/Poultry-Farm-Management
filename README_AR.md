# Poultry Farm Manager V4.2 — نسخة فتح البرنامج أولًا

هذه النسخة مبنية مباشرة على V4.1، لكن تم تغيير مسار التشغيل الأساسي لتجنب اعتماد فتح الصفحة على Supabase أو الإنترنت أو الترجمة.

## ما تم إصلاحه في V4.2
1. **صفحة الدخول تظهر أولًا بشكل مستقل**؛ لا تنتظر Supabase ولا تحميل مكتبة خارجية.
2. **تسجيل حساب جديد محليًا يعمل بدون Supabase**.
3. **تسجيل الدخول المحلي يعمل بدون Supabase**.
4. **Supabase أصبح اختياريًا** ويتم تفعيله فقط عند الحاجة.
5. **إذا كان ملف إعداد Supabase الحقيقي موجودًا، يمكن استيراده ثم تفعيل Supabase من شاشة الدخول.**
6. **إزالة نظام اللغة بالكامل من الواجهة في V4.2** والاكتفاء بالعربية وRTL لتقليل نقاط الفشل أثناء التشغيل. بيانات المزارع والدورات والملاحظات لا يتم تغييرها أو ترجمتها.
7. إضافة طبقة تخزين آمنة: إذا منع المتصفح `localStorage` فلن تتوقف صفحة الدخول بسبب ذلك، ويُستخدم تخزين مؤقت داخل الجلسة بدلًا منه.
8. عدم تشغيل CDN الخاص بـ Supabase تلقائيًا عند فتح البرنامج؛ يتم تشغيله فقط عند وجود إعداد حقيقي أو عند طلب المستخدم تفعيل Supabase.
9. الحفاظ على بيانات الاستعادة المضمنة في `pfm-recovery-data.js` والبيانات التشغيلية السابقة.
10. الحفاظ على منطق الإنتاج والحسابات والمبيعات والمصروفات ومعايير الأداء الموجودة في V4.1.

## طريقة التشغيل
- فك الضغط كاملًا.
- افتح `www/index.html`.
- ستظهر شاشة **دخول / حساب جديد** مباشرة.
- أول مرة: اختر **حساب جديد** وأنشئ حسابًا محليًا.
- بعد إنشاء الحساب يفتح البرنامج.
- Supabase ليس مطلوبًا للدخول الأول أو لاستخدام البرنامج المحلي.

## Supabase
لا توجد مفاتيح Supabase حقيقية مضمنة في هذه الحزمة. لا يتم اختراع أو افتراض أي مفاتيح.
إذا كان لديك ملف إعداد حقيقي، استخدم **استيراد إعداد Supabase (اختياري)** ثم **تفعيل Supabase**.

## ملاحظة مهمة
هذه النسخة هدفها الأساسي كسر حلقة فشل فتح الصفحة. لا تعتبر Supabase أو اللغة أو الشبكة شرطًا لتشغيل البرنامج المحلي.
