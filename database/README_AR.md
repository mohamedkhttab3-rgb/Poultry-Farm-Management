# قاعدة بيانات Poultry Farm Manager — V5.7

## ملفات هذا المجلد
- `original-recovery-from-V5.6.json`: نسخة كاملة من بيانات الاستعادة التي كانت مدمجة بملف V5.6 المرفوع، وليست بالضرورة أحدث بيانات محفوظة الآن في متصفحك.
- `empty-template.json`: نموذج بنية بيانات فارغة. **ليس نسخة احتياطية من بيانات المستخدم الحالية.**
- `sql/`: مخططات Supabase وقواعد البيانات ومسارات الترحيل الأصلية.
- `demo/`: كود البيانات التجريبية Ross 308 تم فصله عن التشغيل حتى لا يمسح البيانات الحقيقية.

## مكان البيانات الحية
يتعامل التطبيق المحلي مع `localStorage` الخاص بحساب المستخدم والمتصفح/المسار؛ ليس ملف ZIP مخزنًا حيًا. انتقل داخل البرنامج إلى **الإعدادات والمعايير > إدارة البيانات والنسخ الاحتياطية > تصدير نسخة JSON كاملة** بشكل دوري ثم احتفظ بالملف في مكان آمن، ويمكن نقله لجهاز آخر عبر زر الاستيراد.

## آلية الاستعادة
- **دمج آمن (الافتراضي):** لا يزيل البيانات الحالية؛ يحتفظ بالسجلات الحالية عند تشابه المعرّفات ويضيف الجديدة غير الموجودة.
- **استبدال كامل:** يغير قاعدة بيانات الحساب بعد تأكيد كتابي صريح ويصدر نسخة احتياطية أولًا؛ يُستخدم فقط عند الحاجة.
- فحص العلاقات بين المزارع والعنابر والدورات قبل الاستيراد.
- تحتفظ كل دورة بمعايير السلالة `standardSnapshot` المخزنة عند تسجيلها.
- Supabase سحابي اختياري. لا يضمن الاستيراد المحلي تلقائيًا استعادة/دمج سجلات الخادم دون مراجعة المزامنة.

لا تنقل كلمة مرور المستخدم أو مفاتيح Supabase الخاصة في أي ملف عام. ملفات JSON قد تتضمن بيانات خاصة بالمزارع ويجب حفظها بشكل آمن.
