# دليل بيانات Poultry Farm Manager V6.3

## مصدر البيانات الحقيقي

- **المصدر المحلي الأساسي:** `localStorage` لكل مستخدم بمفتاح `poultry_farm_management_v34_<userId>`. هذه ليست قاعدة SQL وليست ملفًا يُحدث تلقائيًا داخل ZIP.
- **أرشيف الاستعادة المحلي:** `IndexedDB` باسم `PFM_V63_BACKUP_ARCHIVE` وStore باسم `snapshots`. لكل سجل: `id`, `userId`, `createdAt`, `reason`, `sha256`, `bytes`, `json`. يحتفظ التطبيق بأحدث **12 لقطة مختلفة** لكل حساب عندما يكون IndexedDB وSHA-256 متاحين.
- **نسخة قابلة للنقل:** ملف JSON يصدره المستخدم من الإعدادات بصيغة `PFM_BACKUP_V63` ويحتوي على `data` و`checksum` عند توفر WebCrypto. لا يُعد Excel بديلاً مكافئًا للنسخة الكاملة إلا بعد التحقق من دورته المستقلة.
- **الاتصال السحابي:** ملفات `backend/*.sql` السابقة هي مخططات لـSupabase الاختياري. لا يتم إنشاء خادم أو تشغيل SQL أو مزامنة جهازين تلقائيًا بمجرد استخراج ZIP.

## البنية المنطقية الأساسية

| الجدول / الخاصية | العلاقة والغرض |
|---|---|
| `farms[]` | المزارع، معرف فريد `id` |
| `houses[]` | العنابر، `farmId` يشير إلى `farms.id` |
| `cycles[]` | الدورات، `farmId`, `houseId`، ومعايير السلالة الثابتة `standardSnapshot` |
| `daily[]` | المتابعة اليومية، `cycleId` |
| `weights[]` | الأوزان وCV، `cycleId` |
| `feed[]` | حركة الأعلاف، `cycleId` |
| `meds[]` | الأدوية والتحصينات، `cycleId` |
| `sales[]` | المبيعات والحصاد، `cycleId` |
| `inventory[]` | المخزون، `farmId` |
| `finance{}` | سجلات مالية مرتبطة بالدورات |
| `performanceRules[]` | القواعد المرجعية العالمية (لا تغيّر `standardSnapshot` التاريخي) |
| `settings{}` | إعدادات الحساب والعملة والسلالة الافتراضية |
| `auditLog[]`, `tombstones[]` | سجل العمليات ومؤشرات الحذف السحابي |

## التوافق

- يقرأ V6.3 ملفات النسخ الكاملة القديمة `PFM_BACKUP_V57` و`PFM_BACKUP_V1`، وبنية JSON الخام الصالحة.
- يقرأ V6.3 نسخ `PFM_BACKUP_V63` ويرفضها عند عدم تطابق بصمة SHA-256 المرفقة.
- وضع الدمج الافتراضي يعطي أولوية للسجل الحالي عند تطابق `id`، ويضيف السجلات الجديدة فقط؛ **ليس** دمجًا حقلًا بحقل للتعارضات. وضع الاستبدال يتطلب موافقة كتابية.
- نفس قاعدة البيانات القديمة لم تُحوّل قسرًا إلى SQLite أو SQL؛ لذا لا يوجد تغيير كاسر للمخططات أو الحسابات.

## قيد أساسي

ملف ZIP **لا يمكنه** تسجيل مدخلات المستخدم اللاحقة تلقائيًا بداخله. نسخ IndexedDB مرتبطة ببيانات الموقع في نفس المتصفح وقد تختفي عند تنظيف بيانات الموقع أو تغيير مسار `file://` أو نقل الجهاز. صدّر JSON دوريًا واحتفظ به خارج مجلد البرنامج وفي مكان آمن.

## الخصوصية

لا تشارك JSON الكامل بلا ضرورة؛ فقد يحتوي على تفاصيل المزارع والحسابات. V6.3 يفحص سلامة الملفات، لكنه **لا يشفّر النسخة** ولا يُعد نظام مصادقة محليًا محصنًا ضد من لديه وصول لجهازك. للحسابات المتعددة الحقيقية والإدارة عن بعد استخدم نشرًا آمنًا مع خادم وإعداد صلاحيات Supabase واختبارها.
