الأكواد المصدرية القابلة للتعديل محفوظة بالفعل داخل `../www/` و`../backend/`:
- `www/index.html` شاشات النظام والمنطق الأساسي.
- `www/pfm-v57-data-controls.js` البحث والفلاتر والتصدير والحفظ/الاستعادة الآمنة.
- `www/pfm-v57-data-controls.css` تنسيق الشريط والأزرار.
- `www/pfm-excel-transfer.js` منشئ ومحلل ملفات Excel (.xlsx) دون إنترنت.
- `www/pfm-v53-reference.js` لوحة المؤشرات مع اختيار النطاق الموحد.
- `backend/` مخطط قاعدة البيانات السحابية.

لا تُحرِّك هذه الملفات إلى مجلد source لأن الروابط في index.html تعتمد على موقعها الحالي.
