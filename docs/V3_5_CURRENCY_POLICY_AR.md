# V3.5 — سياسة العملة الموحدة

- العملة يتم اختيارها من مكان واحد: الإعدادات والمعايير.
- العملة المختارة تطبق على جميع المعاملات: العلف، الأدوية، التحصينات، المبيعات، المشتريات/المخزون ذي التكلفة، التكاليف والأرباح والتقارير.
- تم إلغاء قفل تغيير العملة بعد وجود معاملات مالية.
- عند تغيير العملة، يتم تحديث رمز/عملة السجلات الموجودة لتبقى كل المعاملات موحدة تحت عملة المشروع.
- لا يتم إجراء تحويل عملات تلقائي؛ الرقم نفسه لا يتغير عند تغيير العملة. إذا كانت البيانات القديمة تم إدخالها بعملة مختلفة فعليًا، يجب تصحيح القيمة/السعر يدويًا قبل اعتمادها ماليًا.
- حقول العملة داخل التكاليف والأرباح والمبيعات والعلف والأدوية للعرض فقط، ومصدرها الوحيد هو عملة المشروع.
