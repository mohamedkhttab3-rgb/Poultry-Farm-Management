# خطة V3

## الهدف
تحويل البرنامج إلى تطبيق عام يمكن لمالك مزرعة استخدامه من الهاتف أو الكمبيوتر.

## ما أضيف في V3
- دعم المبيعات والحصاد الجزئي مع عدد الطيور والوزن الحي وسعر الكجم.
- تحسين FCR وEPEF باستخدام بيانات البيع عند وجودها.
- CV للأوزان الأسبوعية.
- نسخ احتياطي واستيراد JSON.
- أدوار المستخدمين المقترحة: مالك، مدير مزرعة، مشرف، عامل.
- مخطط قاعدة بيانات PostgreSQL/Supabase.
- استمرار العمل محليًا أثناء تجهيز السحابة.

## المرحلة التالية V3.1
- تسجيل الدخول والحسابات.
- مزامنة سحابية.
- صلاحيات Row Level Security.
- مزامنة Offline/Online.
- إشعارات انخفاض المخزون وانتهاء فترات السحب ومواعيد التحصينات.
- تحويل الواجهة إلى Capacitor Android/iOS.

## المرحلة التالية V4
