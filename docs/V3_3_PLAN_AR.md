# Poultry Farm Manager V3.3

## ما تم إضافته
- إصلاح مسار تسجيل الدخول باستخدام `form submit` بدل الاعتماد على click فقط.
- استعادة كلمة المرور عبر Supabase Auth.
- شاشة تغيير كلمة المرور بعد فتح رابط الاستعادة.
- قراءة الدور من `profiles` بدل تثبيته دائمًا على owner.
- صلاحيات Owner / Manager / Supervisor / Worker.
- شاشة المستخدمين والصلاحيات.
- أساس متعدد المزارع عبر `farm_members`.
- RLS على المزارع والعنابر والدورات والسجلات التشغيلية والمبيعات والمالية.
- دالة آمنة `set_farm_member_role` لتغيير دور العضو.
- منع استخدام Service Role Key داخل التطبيق.

## ملاحظة مهمة
الواجهة الحالية ما زالت تحتفظ بالبيانات المحلية في `localStorage`. ربط الجداول السحابية بالكامل والمزامنة بين الأجهزة وOffline Sync Queue هي مرحلة V3.4/Cloud Sync التالية، بينما SQL في V3.3 يجهز البنية والحماية اللازمة لذلك.

## إعداد Supabase
1. إنشاء مشروع Supabase.
2. تفعيل Email Provider.
3. تشغيل `backend/v3_3_rls.sql` في SQL Editor.
4. إنشاء `www/supabase-config.js` من `supabase-config.example.js`.
5. وضع Project URL وPublishable/Anon key فقط.
6. إضافة Redirect URL الخاص باستعادة كلمة المرور في إعدادات Auth.
7. اختبار إنشاء حساب، التحقق من البريد، تسجيل الدخول، واستعادة كلمة المرور.

## مستويات الصلاحيات
- **Owner:** إدارة كاملة للمزرعة والأعضاء والإعدادات والمالية.
- **Manager:** إدارة تشغيلية وإدارة أعضاء المزرعة، والمالية.
- **Supervisor:** إدخال وتعديل البيانات التشغيلية.
- **Worker:** إدخال البيانات التشغيلية.

هذه الصلاحيات يجب أن تُفرض في RLS؛ إخفاء زر في الواجهة وحده ليس حماية أمنية.
