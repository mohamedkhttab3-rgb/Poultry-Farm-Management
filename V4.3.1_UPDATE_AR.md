# Poultry Farm Manager V4.3.2

- Premium UI/UX refresh and responsive layout.
- PNG logo added for browser/file compatibility; SVG retained as source.
- App favicon/theme color and icon sizes added.
- Arabic/English interface retained and polished; English is the only added interface language.
- Scientific formula review for broiler performance:
  - EPEF/PEF retained: (Livability % × Live Weight kg) / (Age days × FCR) × 100.
  - PI corrected to the common production-index form: (Livability % × ADG g/day) / (FCR × 10).
  - SD for individual sample weights changed from population SD to sample SD (n−1); CV = SD / mean × 100.
  - Current-live rule remains Placement − Mortality − Culls − Sales through today; future entries do not reduce current live birds.
- No currency conversion, cloud architecture, permissions, or database schema changes were introduced.
